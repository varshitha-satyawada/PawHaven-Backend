# PawHaven - Pet Adoption Management System

## Project Overview
PawHaven is a web-based pet adoption management system that connects users with pets available for adoption.

## Technologies Used
- Frontend: React and Vite
- Backend: Spring Boot and Java
- Database: MySQL

## Admin Features
- Add, edit, and remove pet listings.
- View registered users.
- View adoption requests.
- Approve or reject adoption requests.

## User Features
- Register and log in.
- Browse available pets.
- View pet details.
- Submit adoption requests.
- Track adoption request status.

## Database Setup
Create the MySQL database using:

CREATE DATABASE pawhaven_db;

Configure your database username and password in
the Spring Boot application properties.

## Running the Project
1. Start the MySQL server.
2. Start the Spring Boot backend.
3. Install frontend dependencies using npm install.
4. Start the frontend using npm run dev.
